# SnapCrop（咔嚓）

一个轻量级桌面图片裁剪与编辑工具（Windows / Python）。  
支持：裁剪（自由/固定比例）、缩放、旋转、翻转、画布扩展、透明边自动修剪、等分分割导出、撤销/重做。

> SnapCrop (咔嚓) is a lightweight desktop image crop & edit tool built with Python (Tkinter + Pillow).

---

## 功能特性

- **裁剪**
  - 自由裁剪 / 固定比例（1:1、16:9、9:16、4:3、3:4、3:2、2:3、自定义）
  - 裁剪框拖拽手感优化：固定比例时拖边更像常见修图软件
  - 支持键盘微调（方向键移动/扩展/收缩）

- **缩放 / 拉伸**
  - 锁定等比例缩放
  - 自由拉伸

- **变换**
  - 任意角度旋转（已避免连续旋转导致越转越大的问题）
  - 90° / 180° 快速旋转
  - 水平 / 垂直翻转

- **画布与修剪**
  - 画布扩展（Padding：上/下/左/右）
  - 背景：透明（如有 Alpha）/ 白色 / 黑色 / 自定义颜色
  - 自动修剪透明边（Trim Alpha）

- **分割导出**
  - 2×2 / 3×3 / 4×4 或自定义行列
  - 可使用带前缀与随机后缀的命名方式，减少同目录导出覆盖风险

## 下载与运行（Windows）

到 GitHub Releases 下载 `SnapCrop.exe`，解压后双击运行即可。  
如果系统提示安全警告，这是 Windows 对未签名程序的常见提示，可选择“仍要运行”。

---

## 使用方法

1. 点击 **打开（Ctrl+O）** 选择图片  
2. 在左侧选择功能页：缩放 / 裁剪 / 变换 / 分割  
3. 需要裁剪时：拖出裁剪框 → **Enter 应用裁剪**  
4. 保存：**Ctrl+S** 或点击保存按钮  
5. 分割：选择等分方式 → 选择输出目录 → 自动导出

---

## 快捷键与操作

- **Ctrl+O**：打开图片  
- **Ctrl+S**：保存图片  
- **Ctrl+Z**：撤销  
- **Ctrl+Y**：重做  
- **Enter**：应用裁剪  
- **Esc**：清除裁剪框  
- **滚轮**：缩放  
- **中键/右键拖拽**：平移画布  
- **方向键**：移动裁剪框（Shift=10px）
- **Ctrl + 方向键**：向外扩展裁剪框  
- **Ctrl + Shift + 方向键**：向内收缩裁剪框  
- **Shift**：自由模式下临时 1:1；已有框时临时保持当前比例  
- **Space**：拖拽边/角时临时“移动裁剪框（保持尺寸）”
